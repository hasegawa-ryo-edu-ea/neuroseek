# 運用手順

英語版: [RUNBOOK.md](RUNBOOK.md)

大きな実験の前に `./up.sh --doctor` を実行してください。`./up.sh --smoke` は境界付きの合成検証経路です。`./up.sh --trial` は実データから決定的にコンパイルした部分グラフを使う境界付き run です。`./up.sh` は本番学習を切り離して開始または再開し、対話時にはリーダーを接続します。

切り離したサービスは `./status.sh`、ログは `./logs.sh` で確認します。SSH を再接続した後に端末ダッシュボードへ戻るには、再び `./up.sh` を実行します。実行中の学習器はビルド、semantic 準備、CUDA 事前検査より先に検出されるため、再接続で学習用 GPU と競合しません。最初の起動時は、ランチャーが `NEUROSEEK trainer detached:` を表示するか TUI を出すまで意図的に切断しないでください。フル semantic 準備は切り離しサービスより前に実行されます。中断した準備はアトミックなチェックポイントを使い、次の `./up.sh` で安全に再開します。

`./down.sh` は正常終了を要求し、永続データを保持します。失敗からの復旧のために `data/processed/` や `runs/` を削除しないでください。まずクラッシュレポートと最新チェックポイントを確認します。
