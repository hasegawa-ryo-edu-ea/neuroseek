# 実験の原則

英語版: [EXPERIMENT_DESIGN.md](EXPERIMENT_DESIGN.md)

科学的な評価単位は自由文ではなく、構造化された `QuerySpec` です。学習・検証・テストの生成器は別々のシードと永続化した分割ファイルを使います。グラフ生成器は行動クローニング用に有効なデモ経路を与えられますが、最適経路を保証するものではありません。

ベースラインは固定探索、該当する場合の意味検索のみ、手書き hybrid です。すべて同じ保持タスクで、回答正確度、証明有効性、調べたノード／エッジ、命令数、ANN 呼び出し、クレジット、遅延、テレメトリがあればエネルギーを計算します。適用できないベースラインはそのように報告します。

合成グラフは smoke テストに限定します。trial モードと full モードは、処理済み実データの manifest がなければ起動を拒否します。
