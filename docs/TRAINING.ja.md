# 学習と復旧

英語版: [TRAINING.md](TRAINING.md)

`full.toml` の実行時間上限は 180,000 秒（50 時間）です。ランチャーは常に切り離した学習サービスを作成または再開し、ダッシュボードの接続がそれに影響してはいけません。最初の full semantic 準備には、別の 6 時間の fail-closed 上限があります。この上限に達すると、学習開始前にアトミックにチェックポイントを書いて終了します。`./up.sh` を再実行すると準備を再開します。準備済みホストでは、初回起動も上限のないセットアップにせず、要求された 60 時間の範囲内に収まります。

各チェックポイントにはモデル、オプティマイザ、フェーズ、最良メトリクス、設定、RNG 状態、タスク生成器の RNG／カーソル、保持データの除外集合、フェーズ状態を含めます。trial/full の再開は、タスク生成器状態がないチェックポイントを拒否します。シードからタスク列を黙って再生しません。チェックポイントは同じディレクトリの一時ファイルに書き、fsync 後にアトミックな rename をします。`latest.ckpt` と `best.ckpt` は周期的な保持とは独立して残します。

報酬の記録はタスクアダプタで要素化します。方策の結果が回答クレジットを受けるのは、独立した証明検証器がグラフ根拠を受理した後だけです。決定的な固定シード検証では保持分割のシードを使います。

full カリキュラムには、実際の CUDA score/CSR プローブ、観測したハードウェアコスト標本、BC ウォームアップ、2〜3 ホップ RL、4〜6 ホップの distractor、intersection エピソード、semantic-hybrid エピソード、robustness distractor、Jetson 特化 PPO、実体化したテストの決定的ベースライン出力という具体的なハンドラがあります。未知のフェーズ名は fail-closed です。フェーズ時間と昇格しきい値は UI ではなく、有効な設定と run manifest に置きます。

本番フェーズに入るたび、NEUROSEEK は不変の検証 artifact から選んだ固定代表集合（利用可能な path、distractor、intersection、semantic-hybrid、robustness）でチェックポイント済み方策を実行します。実際のプログラムは `runs/<id>/traces/reference-*.json` と永続的な `traces/strategy_evolution.json` に書きます。参照証明は監査用にだけ保持し、方策の実行には教師経路を渡しません。

`semantic_bounded` を使えるのは `--trial` だけです。既定の full run は、`data/processed/semantic_full` が全コンパクトグラフ entity ID に対するハッシュと完全整列の検証を通過するまで開始を拒否します。部分ベクトルを完全な Wikidata5M semantic coverage として示さないための意図的なゲートです。

full モードでは、温度が危険域に達するとチェックポイントを書いて学習器を停止します。持続する熱スロットリング下で固定された時間予算を消費するより、冷却後に再開する方を優先します。
