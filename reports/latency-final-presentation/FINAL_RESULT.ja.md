# NEUROSEEK Jetson 低レイテンシーモデル：最終結果

英語版: [FINAL_RESULT.en.md](FINAL_RESULT.en.md) · 詳細なリリースノート: [RELEASE_NOTES.ja.md](RELEASE_NOTES.ja.md)

レイテンシー特化チェックポイントは、親モデルと同じ Wikidata5M ベースの固定保持テスト 256 件、同じグラフ、semantic artifact、CUDA exact backend で評価しました。

| 指標 | 親モデル | 最終モデル | 変化 |
| --- | ---: | ---: | ---: |
| 平均エンドツーエンド遅延 | 31.92 ms | 31.11 ms | -2.56% |
| p95 エンドツーエンド遅延 | 57.10 ms | 53.02 ms | -7.14% |
| タスクあたり平均計算クレジット | 233.98 | 146.02 | -37.59% |
| 正答率／有効証明率 | 98.05% | 97.27% | -0.78 ポイント（2 件） |

最終チェックポイントは、精度をわずかに交換して遅延と探索コストを下げました。これは単一 Jetson と一つの固定テストセットでの結果です。信頼区間、外部 SOTA 比較、自然言語の質問応答評価を示すものではありません。詳細は [日本語プレゼンテーション](report.html) と `exports/` の正式な出力を参照してください。
